# Локальные данные и независимая публикация

Приложение работает на GitHub Pages с IndexedDB, без аккаунтов и сервера. Это обеспечивает офлайн-работу и отсутствие отправки измерений, но данные не синхронизируются между устройствами и могут быть удалены браузером. Для ручного переноса и восстановления предусмотрены JSON-копии. Каталог остаётся без service worker; у приложения собственные base, scope и имена кешей/базы.
