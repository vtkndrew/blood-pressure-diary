# Дневник давления и пульса

**Сеанс**: группа последовательных измерений одного человека с общей датой, временем и заметкой.

**Измерение**: пара значений верхнего и нижнего давления и необязательное значение пульса, введённые пользователем.

**Среднее сеанса**: арифметическое среднее измерений сеанса; для пульса учитываются только заполненные значения.

**Среднее периода**: арифметическое среднее средних сеансов, каждый сеанс имеет одинаковый вес.

**Черновик**: незавершённый ввод нового или редактируемого сеанса, ещё не включённый в журнал и статистику.
